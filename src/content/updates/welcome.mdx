## Adding an update

Every update is a single MDX file in `src/content/updates/`. The file name
becomes the address, so `first-release.mdx` is published at
`/updates/first-release`.

At the top of the file, export a `meta` object with a title, a date and a
one-sentence summary:

```js
export const meta = {
  title: "Our first release",
  date: "2026-10-01",
  summary: "What shipped, and what we learned.",
};
```

Everything below that is regular Markdown, with the option to use React
components when you need them.

## Writing style

- Keep it plain and specific: what happened, and why it matters.
- Link to the pull requests and repositories involved.
- Do not include compensation figures or promise outcomes.
